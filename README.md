# RiskBox — терминал для Binance Futures на Solid.js

Веб-приложение для планирования сделок по бессрочным фьючерсам Binance:
рисуете long/short прямо на графике — размер позиции считается от риска
в USDT, растянутого между ценой входа и стоп-лоссом.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`). Для сборки
продакшен-версии: `npm run build` (результат — в `dist/`, статика, можно
положить на любой хостинг).

Требуется Node.js 18+. Никаких API-ключей не нужно — используются только
публичные, не требующие авторизации эндпоинты Binance Futures.

## Возможности

- **Реальные котировки Binance Futures** — свечи и объём грузятся через
  `GET /fapi/v1/klines`, дальше обновляются вживую по WebSocket
  (`kline_<interval>`). Список пар и их 24-часовой объём/изменение —
  через `/fapi/v1/ticker/24hr` + поток `!ticker@arr`.
- **Инструменты рисования** на главном графике: горизонтальная линия,
  горизонтальный луч, трендлиния, длинная/короткая позиция. Все объекты
  можно перетаскивать, выделять и удалять (по одному или все сразу),
  хранятся отдельно для каждой монеты.
- **Расчёт позиции от риска.** Инструмент Long/Short рисуется протяжкой
  от входа к стопу; размер позиции в USDT считается по формуле
  `риск × вход / |вход − стоп|` и обновляется вживую при изменении
  риска в шапке или перетаскивании уровней входа/стопа/тейка. Там же
  считается R:R-отношение (`|TP − вход| / |вход − стоп|`).
- **Поле «Риск, USDT»** в шапке, минимум 0.01, шаг 0.01 — управляет
  размером всех нарисованных позиций сразу.
- **Три типа ордера**: лимит, маркет и **стоп-ордер**. Для стоп-ордера
  цена входа обязана лежать по ту сторону от рыночной, в которую ожидается
  продолжение движения — выше рынка для Long (вход на пробое вверх), ниже
  рынка для Short (вход на пробое вниз). Инструмент рисования Long/Short
  сам подправит точку входа под это правило (с уведомлением), а кнопка
  «Открыть позицию» дополнительно проверяет это перед открытием — точно
  так же, как Binance отклонил бы такой стоп-ордер ошибкой -2021 «Order
  would immediately trigger.».
- **Лог API-запросов.** При нажатии «Открыть позицию» (и на Buy/Sell) в
  консоль браузера построчно выводится, что именно было бы отправлено на
  `POST /fapi/v1/order`: ордер на вход (LIMIT/MARKET/STOP_MARKET — в
  зависимости от выбранного типа), плюс закрывающие STOP_MARKET и
  TAKE_PROFIT_MARKET (reduceOnly) на стоп и тейк, с точными полями
  (`symbol`, `side`, `type`, `quantity`, `price`/`stopPrice`,
  `timeInForce`, `reduceOnly` и т.д.).
- **Сайдбар с выбором монеты** — открывается/закрывается кнопкой
  «Пары», поиск по тикеру, сортировка по объёму.
- Панель «Позиции» — локальный журнал открытых/закрытых сделок,
  привязанных к нарисованным объектам.

## Важно: реальные ордера

Действия Market и закрытия отправляют реальные ордера Binance USDT-M Futures
через подписанный backend API. Backend использует production API Binance;
перед нажатием проверьте инструмент, сторону, размер и стоп. Не считайте
локальный журнал позиций подтверждением фактического состояния счета.

Отложенные входы Limit и Stop/Stop-Market временно отключены: приложение пока
не гарантирует установку защитного стопа после исполнения входа. Не отправляйте
их напрямую в backend, пока эта защита не реализована и не проверена.

## Структура проекта

```
src/
  api/binance.js        REST + WebSocket обёртка над Binance Futures
  utils/risk.js          формулы размера позиции, R:R и правило стоп-входа
  utils/binanceOrder.js   сборка и консольный лог payload'ов Binance API
  utils/format.js         форматирование цены/объёма/процента
  store/store.js          общее реактивное состояние (Solid signals/store)
  components/
    Header.jsx            шапка: ордер, риск, плечо, тулбар, заметка
    Toolbar.jsx            кнопки инструментов рисования
    MainChart.jsx          главный график + весь движок рисования
    Sidebar.jsx             список пар
    PositionsPanel.jsx      журнал позиций
    StatusBar.jsx / Toast.jsx
```

## Возможные доработки

- Реальное исполнение ордеров через собственный бэкенд с подписанными
  запросами к Binance.
- Сохранение рисунков между сессиями (сейчас всё в памяти вкладки).
- Перетаскивание правого края бокса позиции для изменения его ширины
  по времени (сейчас ширина фиксирована при создании).
