# Trading Frontend

React приложение для торговли криптовалютой с графиками в реальном времени, инструментами для технического анализа и управлением позициями.

## Основные возможности

- **Графики в реальном времени**: Отображение нескольких таймфреймов (5m, 1h, 1d) одновременно
- **Инструменты для рисования**: Линии поддержки/сопротивления, трендовые линии, позиции Long/Short
- **Управление позициями**: Открытие и закрытие позиций с расчетом риска и прибыли
- **Интеграция с Binance**: Получение данных о ценах и символах через WebSocket
- **Расчет риска**: Автоматический расчет размера позиции на основе риска в USDT
- **Time & Sales**: Отображение сделок в реальном времени
- **Скриншоты**: Сохранение скриншотов графиков для анализа

## Технологии

- React 19
- Lightweight Charts с расширениями для инструментов рисования
- Vite
- WebSocket для реального времени

## Конфигурация

### API Backend

По умолчанию приложение использует `http://localhost:3001/api` как базовый URL API.

Для изменения используйте переменную окружения:
```bash
VITE_API_BASE_URL=http://your-api-url/api npm run dev
```

### Зависимости

Приложение использует локальные зависимости:
- `lightweight-charts` с расширениями для инструментов рисования
- `trading-charts-with-tools` - библиотека с расширенными возможностями графиков

Убедитесь, что эти зависимости доступны локально или установите их через npm.

## Основные функции

### Графики

- Множественные таймфреймы на одном экране
- Синхронизация масштаба и прокрутки между графиками
- Интеграция с Binance WebSocket для данных в реальном времени

### Инструменты рисования

- Линии тренда
- Позиции Long/Short с автоматическим расчетом риска
- Редактирование и удаление инструментов
- Сохранение инструментов в localStorage

### Управление позициями

- Открытие позиций с расчетом размера на основе риска
- Различные типы ордеров (Market, Limit, Stop Market)
- Автоматический расчет стоп-лосса и тейк-профита
- Закрытие позиций с экспортом данных

### Time & Sales

- Отображение сделок в реальном времени
- Фильтрация по типу (покупка/продажа)
- Агрегированная статистика

## Интеграция с Backend

Приложение интегрируется с `trading-back` сервером для:
- Сохранения позиций
- Загрузки скриншотов
- Получения исторических данных
- Управления API ключами Binance

## Разработка

Проект следует атомарной архитектуре:
- Каждый хук выполняет одну задачу
- Компоненты разделены по ответственности
- Стили вынесены в отдельные файлы
- Логика бизнес-процессов в хуках и утилитах
